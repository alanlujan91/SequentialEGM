
+++ {"part": "abstract"}

Heterogeneous agent models with multiple decisions face a computational dilemma. Joint optimization over all choices is slow; strong separability restrictions speed computation but rule out economically interesting interactions. We resolve this tension through sequential decomposition. Economically simultaneous decisions need not be computationally joint. By decomposing problems into sequential stages, each stage exploits the Endogenous Grid Method's efficiency, chaining speed gains across decisions. The resulting non-rectilinear grids require specialized interpolation. We develop Curvilinear Grid Interpolation for topologically regular grids and apply Gaussian Process Regression for fully unstructured grids. The method solves multidecision heterogeneous agent models orders of magnitude faster than grid search approaches.

# Introduction

Solving heterogeneous agent models with multiple decisions has traditionally required either nested optimization (which is slow) or restrictive assumptions about preferences (which limits economic relevance). The Endogenous Grid Method revolutionized consumption-savings problems by inverting first-order conditions, but extending this insight to problems with multiple continuous choices and high-dimensional state spaces has remained an open challenge. We show how to decompose such problems into sequential stages that each admit an EGM step, effectively chaining the efficiency gains across decisions.

## Background and Literature

Dynamic heterogeneous agent models require solving high-dimensional optimization problems at each point in a potentially large state space. Standard grid search approaches impose substantial computational costs, particularly when state spaces grow large or when multiple continuous decisions must be made jointly. {cite:t}`Carroll2006` introduced the Endogenous Grid Method (EGM), which inverts the first-order condition to construct optimal policies without explicit optimization. By starting from a grid of post-decision states and working backward to recover pre-decision states, EGM transforms problems that required hours of computation into tractable exercises, enabling researchers to focus on estimation and simulation rather than numerical solution algorithms. The original method applied to consumption-savings problems with a single control variable and state variable. Subsequent work has expanded EGM's applicability to broader problem classes (see {cite:t}`Barillas2007, Maliar2013, Fella2014, White2015, Iskhakov2017`), each extension addressing specific structural features while introducing its own limitations.

This paper introduces a new approach to EGM in a multivariate setting. We call the method Sequential EGM (or EGM$^n$) and show how to break down complex problems into a sequence of simpler, smaller, and more tractable problems, along with developing multidimensional interpolation methods that make this practical. The key distinction between EGM$^n$ and nested approaches lies in how we treat the computational structure. Nested EGM still embeds a grid search or root-finding step within an outer EGM step. Sequential EGM chains multiple EGM inversions, exploiting separability to avoid optimization entirely when applicable. This requires stronger structural assumptions (separable utility or independent transitions), but the payoff is elimination of costly inner-loop optimization and generation of interpretable intermediate value functions at each stage. The method reveals the problem's natural information flow: which decisions shed state variables, which create new post-decision states, and how to order computations to minimize dimensionality at each step.

{cite:t}`Carroll2006` introduced the Endogenous Grid Method to accelerate solution of dynamic stochastic consumption-savings problems. The method starts with an exogenous grid of post-decision states and uses the inverse of the first-order condition to find the optimal consumption policy that rationalizes those post-decision states. Given the optimal policy and post-decision states, the initial pre-decision state that leads to the optimal policy follows directly. The original method applied to models with one control variable and one state variable. {cite:t}`Barillas2007` extend the method to multiple control variables (labor-leisure choice) and a second state variable for stochastic persistence.

Extensions broadened EGM's scope along two dimensions: relaxing structural assumptions and expanding to multidimensional problems. Handling non-convexities required new techniques. {cite:t}`Fella2014` relax continuity requirements with the Generalized Endogenous Grid Method (GEGM), which evaluates candidate solutions from first-order conditions in overlapping regions. {cite:t}`Druedahl2017` introduce G2EGM, extending the generalized approach to multiple controls and states while handling occasionally binding constraints. {cite:t}`Iskhakov2017` incorporate discrete choices through extreme value errors, though their application remains restricted to single control and state variables. {cite:t}`Clausen2020` formalize EGM's applicability to discrete choice models and analyze nested solution approaches.

Multivariate problems presented distinct challenges. {cite:t}`White2015` formalized conditions under which EGM applies to multidimensional problems and developed interpolation methods for the curvilinear grids that result. {cite:t}`Iskhakov2015` characterize a triangular structure in systems of first-order conditions that permits sequential solution by substitution. This triangular structure is less restrictive than the full separability we exploit, but requires root-finding operations that our approach eliminates when separability holds. {cite:t}`Druedahl2021` develop nested EGM (NEGM) for multiple continuous controls, reducing computational complexity relative to joint optimization. Nested methods still embed optimization or root-finding within outer EGM loops, retaining some grid search overhead. {cite:t}`Ludwig2018` propose Delaunay triangulation for interpolating on the unstructured endogenous grids that arise in such problems, though triangulation costs can offset the gains from avoiding grid search.

Related approaches exploit first-order conditions without explicit EGM structure. {cite:t}`Maliar2013` develop the Envelope Condition Method, which shares EGM's strategy of avoiding numerical optimization, though the method's forward-solution structure restricts it to infinite-horizon problems. {cite:t}`Arellano2016` apply envelope condition methods to sovereign default models, achieving EGM-like efficiency gains. Machine learning techniques offer alternative approaches to high-dimensional problems. {cite:t}`Scheidegger2019` apply Gaussian Process Regression to compute global solutions for high-dimensional stochastic problems. {cite:t}`Maliar2021` use neural networks to approximate systems of equations characterizing dynamic economic models.

## Methodology and Contributions

Sequential EGM (or EGM$^n$) decomposes multidecision problems into stages that each admit an EGM inversion. The decomposition respects the timing of uncertainty: all within-period decisions must be made under the same information set to preserve the original problem's structure. Introducing asynchronous uncertainty—where shocks resolve between subproblems within a single period—would alter the solution by providing information unavailable to agents in the original formulation. Each stage applies EGM when the subproblem structure permits inversion of first-order conditions. When a subproblem lacks the separability or invertibility required for EGM, standard optimization methods apply. The non-rectilinear grids that emerge from EGM inversions require specialized interpolation. We develop Curvilinear Grid Interpolation for grids that preserve topological structure despite geometric warping, and apply Gaussian Process Regression for fully unstructured grids where even topology breaks down.

The method chains multiple EGM inversions without embedding optimization within outer loops, unlike nested approaches. When separability permits this chaining, grid search is eliminated entirely. The sequential structure exposes intermediate value functions and marginal values at each decision stage, making explicit the problem's information flow. These intermediate functions—which emerge naturally from the solution process—reveal how decisions shed state variables and how information propagates through the problem.

Relative to NEGM, which embeds root-finding or optimization within an outer EGM step, our approach requires stronger structural assumptions (full separability rather than triangularity) but avoids all optimization overhead when those assumptions hold. The separation of decisions into stages clarifies which subproblems can exploit EGM and which require alternative methods, providing transparency about where computational costs arise.
